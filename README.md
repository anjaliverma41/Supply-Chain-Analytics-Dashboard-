Supply Chain Analytics Dashboard – Power BI

**Objective - **

This project is an interactive Supply Chain Analytics Dashboard built using Microsoft Power BI. It provides insights into inventory, suppliers, warehouses, customer orders, sales, revenue, and profitability.
